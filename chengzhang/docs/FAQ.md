# 公众号连接常见问题

适用：用户询问 AppID、AppSecret、API Token、IP 白名单，或首次连接公众号遇到问题时。Agent 按当前问题选择回答，不一次倾倒整份 FAQ。用户缺少公众号配置时，主动提供获取入口与配置步骤；已有配置直接复用。

获取路径依据用户确认的新版微信开发者平台及本项目配置页（2026-10-04）。不要凭旧知识改回“微信公众平台 → 设置与开发 → 基本配置”，也不要给旧的 `mp.weixin.qq.com/wxamp/devprofile/get_profile` 链接。如果界面与下文不一致，先询问用户目前看到的菜单名称，或核对官方最新说明；不要编造按钮或要求发送包含密钥的截图。

## AppID 和 AppSecret 是什么？与成章 Token 有什么区别？

AppID 是你微信公众号的身份编号，通常以 `wx` 开头；AppSecret 是该公众号调用接口使用的密钥。成章用它们连接微信，把文章保存到你的公众号草稿箱。

它们属于你的微信公众号，不是个人微信账号，也不是成章登录密码。成章的 API Token（以 `wp_` 开头）则用于让 Agent 访问你的成章账号。

- AppID、AppSecret：只在成章的公众号配置网页填写。
- 成章 API Token：保存在你电脑的技能配置文件，供 Agent 使用。

不要让用户把 AppSecret 或 API Token 发到聊天中。

## 在哪里获取 AppID 和 AppSecret？

1. 打开 [微信开发者平台](https://developers.weixin.qq.com/platform) 并登录。
2. 在导航栏找到 **我的业务与服务**，选择要连接的 **公众号**。
3. 打开该公众号页面的 **基础信息**，找到 **AppID** 和 **AppSecret**；**APP IP白名单** 也在这里。
4. 按页面实际提示查看或获取密钥、完成身份验证，并直接填入成章配置页。不要默认要求重置密钥。

如果有多个公众号，先确认选择的是要上传草稿的那个。看不到公众号或密钥时，先确认登录账号是否具有相应管理权限；让有权限的管理员操作。不把“重置 AppSecret”作为默认排查步骤：更换密钥可能影响已经使用它的其他工具。

不要承诺某个“查看／重置”按钮、固定验证方式或显示次数，除非当前界面已确认。

## 拿到后怎么配置？

1. 打开 [成章公众号配置页](https://chengzhang.page/settings/wechat)，登录你的成章账号。
2. 将公众号的 AppID 和 AppSecret 填到对应输入框。
3. 点击 **保存并测试连接**。
4. 显示连接成功后即可使用；若提示白名单问题，按下一条处理。

已有配置不需要重复填写；更换电脑或 Agent 时，复用同一成章账号的公众号配置即可。`check` 只核对服务账号和已保存配置，不代表微信连通性已经验证。需要实际验证时，用网页检测或调用 `POST /api/config/test`，以 `data.ok` 为准。

## 提示 IP 白名单问题（40164）怎么办？

1. 在成章配置页点击 **保存并测试连接**，复制页面显示的服务器公网 IP。
2. 回到 [微信开发者平台](https://developers.weixin.qq.com/platform) → **我的业务与服务** → **选择公众号** → **基础信息** → **APP IP白名单**。
3. 添加刚复制的服务器 IP，保留已有白名单条目，保存。
4. 回成章页面再次测试连接。

加的是成章服务端出口 IP，不是用户电脑或家里路由器的 IP。不要在技能中写死某个 IP；使用本次检测结果。页面没有给出有效公网 IP 时，联系服务管理员确认，不让用户猜测。

## 没有公众号，或草稿上传提示没有权限怎么办？

这项功能需要你具有管理权限的微信公众号。没有公众号时，可以先使用成章编辑和预览；如果要上传草稿，需要先注册或取得相应公众号的管理权限。

能获取 access_token 不等于一定具有草稿接口权限。若返回权限错误，按实际错误码核对该公众号在微信侧的接口权限；不要承诺所有订阅号／服务号、未认证账号都能上传，也不要未经核对就让用户付费认证。账号类型与认证要求以微信官方当前规则为准。

## 口令遗失或连接失败，应该重置哪个？

- 成章返回 401：先到 [API Token 页面](https://chengzhang.page/tokens) 检查或新建成章 Token，再更新本机配置；不要因此重置公众号 AppSecret。
- 微信凭证错误：核对是否选对公众号、AppID 和 AppSecret 是否匹配，按微信错误信息处理。
- 40164：处理 APP IP白名单。
- 网络连接失败：先检查网络与宿主授权，不直接认定凭证无效。

## 配置完成后会自动群发吗？

不会。技能仅在用户要求上传时创建公众号草稿；最后向粉丝发布仍由用户在公众号后台操作。用户只问获取／配置方法时，回答并帮助连接，不顺带创建草稿。
